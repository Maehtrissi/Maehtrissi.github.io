# Sponti E-Mail-Vorlagen für Supabase Auth

Diese zwei Mails verschickt Supabase selbst (nicht unsere Warteschlange). Sie werden im Supabase-Dashboard eingefügt:

**Authentication → Emails → Templates**

| Vorlage in Supabase | Betreff | Datei |
|---|---|---|
| Confirm signup | Bestätige deine E-Mail-Adresse für Sponti | `supabase-mail-bestaetigen.html` |
| Reset password | Dein neues Passwort für Sponti | `supabase-passwort-zuruecksetzen.html` |

Jeweils den ganzen Inhalt der Datei in das Feld «Message body» kopieren und speichern.
Hinweis: Diese Vorlagen gelten für Kunden- und Anbieterkonten gleichermassen.
